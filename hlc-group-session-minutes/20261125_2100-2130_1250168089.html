【漣さん】: WordPress 移行・LP ページ整備と AI 活用

相談内容

Ameba Ownd から WordPress（エックスサーバー）への移行を進めており、以前はエクスポートデータがうまくいかないと思っていたが、実際に開いてみたら YouTube 埋め込みやメニューページを含めてほぼ正常に移植できていた。テーマは AFFINGER6 を使用し、パーマリンクの設定まで完了している。

現在の課題は以下の 2 点：

  • salon漣.com をホームページとして機能させながら、既存の LP コンテンツを「固定ページ」として切り出し、広告からの流入先として設定したい
  • ブロックエディターの操作に不慣れで、既存コンテンツをどう移植すればよいか分からない

また、ChatGPT の無料版を使って CSS の調整を行っているが、画像添付の上限がすぐに来てしまい、スクリーンショットを使えず言葉だけで進めている状況。

川谷さんの反応・提案

① ブロックエディターでの移植手順

「ブロックを選択して 3 点メニューから『HTML 編集』を開くと、そのブロックのコードが表示される。それをコピーして、移植先の固定ページで『カスタム HTML』ブロックを追加し、貼り付けて更新すれば反映できる。2 つのタブを並べながら 1 ブロックずつ移植していくのが現実的。」

一気に全ページを移植するのは難しいが、ブロック単位で地道に移植していけばページとして完成する。

② CSS・コード装飾の AI 活用

「コードを 1 個ずつ書き換えるのは僕も全然できないので、ChatGPT に『色合いをこう変えたい』『フォントをこうしたい』と指示すると、それ用のコードを作ってくれる。そのコードを貼り付けて反映するというやり方でコードベースの編集ができる。」

CSS で全体をコントロールできているなら、ブロックごとの個別調整は不要な場合も多い。

③ MCP アダプタープラグインの紹介

WordPress と ChatGPT を MCP（Model Context Protocol）でつなぐプラグインを使うと、ChatGPT から直接 WordPress のページを編集・反映させることができる。川谷さんが zip ファイルをチャットワークで共有。インストールは「プラグイン → 新規追加 → アップロード」から行う。

「ページがぶっ壊されることはないが、既存データのバックアップはとっておいた方がいい。」

なお、ChatGPT 公式の WordPress 向け MCP プラグインも存在するとのことで、Cursor 経由より直接つなぐ方がスムーズかもしれないと言及。

④ ChatGPT 有料プランの活用方針

  • 月額約 1,500 円のプランでも基本的な作業は可能
  • 川谷さんや【秋山さん】が使っている ChatGPT Plus（月 3,000 円）であれば、WordPress 1 ページを作るには容量・修正回数ともに十分
  • AI の変動が激しいため、年間課金は避け、月単位で入って翌月解約を先に設定しておく運用を推奨

「よっぽど信頼できるもの以外、年間課金せず、やるにしても月額で入って、翌月には解約されるように先に解約もセットで課金するというケチくさい技を使ってます。」

解約後も会話履歴・データは消えず、使えるトークン数に制限がかかるだけ。

⑤ 集客状況と広告改善の方向性

LINE 登録がここ最近で 2〜3 人急増し、新規問い合わせ・新規顧客も入ってきていることを【漣さん】が報告。ページを見て来てくれているとのこと。

川谷さんからは、導線自体は機能しているとしたうえで、次の改善点を提案：

  • 広告動画のシナリオ設計を見直す
  • 画角を工夫し、視聴者が疑似体験しやすい映像にする
  • LP に埋め込んでいる動画はすでにおしゃれで疑似体験感があるので、さらに細かい施術の様子を見せるなどの追加が有効

考え方・マインドセット

コードは自分で書かなくていい。AI に「指示」して「貼る」だけ

WordPress のコード編集は、自分でゼロから書く必要はない。「色をこう変えたい」「フォントをこうしたい」という日本語の指示を ChatGPT に出し、返ってきたコードをそのまま貼り付けて反映する、というサイクルで十分に編集できる。コードの仕組みを理解することよりも、「何を変えたいか」を言語化する力の方が重要。

AI ツールへの課金は「月単位・解約前提」で柔軟に

AI サービスは変動が激しく、今月最良のツールが来月には別のものに変わることもある。年間課金でロックインされるリスクを避け、必要な時期だけ月額プランに入り、翌月解約を先に設定しておく運用が合理的。

導線が機能しているなら、次は「質」の改善へ

集客の仕組み（ページ・LINE 導線）がある程度機能し始めたら、次のステップは量を増やすことよりも、広告動画のシナリオや画角など「質」の改善に移行する。疑似体験できる映像設計が、問い合わせ率の向上につながる。

体調・ペースを最優先にしながら進める

学習や作業のペースが他の参加者と合わないと感じても、焦る必要はない。体の状態を第一にしながら、できる範囲で着実に進めることが長期的な成果につながる。
